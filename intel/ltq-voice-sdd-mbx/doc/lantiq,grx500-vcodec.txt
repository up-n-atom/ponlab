* Lantiq GRX500 VCODEC

Required properties:
- compatible: must be equal to "lantiq,grx500-vcodec"
- reg: SPI chip select line number the VCODEC is attached to
- interrupts: interrupt number the VCODEC is attached to
- interrupt-parent: reference to the gic
- pinctrl-names: must be equal to "default"
- pinctrl-0: reference to pincontrol defining how and which pins to use for
  the VCODEC SSI interface.
- slic child node if a SLIC200 family device is used with these properties:
    -compatible: must be equal to "lantiq,slic200"
    -dcdc_type: String from below list describing the DC/DC converter type used:
        IBB
        CIBB
        IFB
        CIFB

Optional properties:
- spi-max-frequency: the maximum SPI frequency used by the master, limit to 8MHz

Example:
        vcodec@5 {
                compatible = "lantiq,grx500-vcodec";
                spi-max-frequency = <8000000>;
                reg = <5>;
                interrupts = <217>;
                interrupt-parent = <&gic>;
                pinctrl-names = "default";
                pinctrl-0 = <&pinctrl_vcodec &pinctrl_vcodec_conf>;


                slic200@0 {
                        compatible = "lantiq,slic200";
                        dcdc_type = "IBB";
                };
        };
